## Moonrad · Voidnaut

At [Moonrad](https://moonrad.com), we're building **Voidnaut** — a pre-confirmation threat detection system for Base L2.

Voidnaut monitors the Flashblocks stream (~200ms intervals) and flags malicious activity inside the ~1.8s window before block confirmation. Designed for teams that need to protect contracts, wallets, and deployers before damage is done.

- Real-time Base activity monitoring
- Deterministic hot-path (no LLM on critical decisions)
- Alert pipelines and webhook delivery
- B2B API surface

→ [voidnaut.app](https://voidnaut.app)
